# Time Travel Museum

An interactive, GitHub Pages-ready museum. Choose galleries in any order, inspect illustrated exhibit labels, and solve one short curator challenge in each room.

## Galleries
- **Deep Time** — dinosaur fossils and scientific uncertainty.
- **Ancient Worlds** — the Rosetta Stone and parallel scripts.
- **Human Origins** — early stone tools and archaeological evidence.
- **Future Studio** — a speculative design exercise, not a prediction.

## Run locally
Open `index.html` in a modern browser. No build step or external runtime dependencies are needed.

## Publish with GitHub Pages
1. Upload `index.html` and this `README.md` to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose `main` and `/ (root)` and save.
4. Open the Pages URL shown in Settings → Pages after deployment finishes.

Challenge stamps are saved in the visitor's browser. Sources: [Natural History Museum — Stegosaurus](https://www.nhm.ac.uk/discover/dino-directory/Stegosaurus.html), [Smithsonian — T. rex](https://www.si.edu/newsdesk/factsheets/tyrannosaurus-rex), [British Museum — Rosetta Stone](https://www.britishmuseum.org/collection/object/Y_EA24), [Smithsonian Human Origins — Stone Tools](https://humanorigins.si.edu/evidence/behavior/stone-tools/early-stone-age-tools), [NASA — Humans in Space](https://www.nasa.gov/humans-in-space/).

The gallery pictures are simple illustrations, not photographs of specific artifacts or exact specimen reconstructions.
